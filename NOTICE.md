# Уведомление

Averon Import предназначен для внутренней автоматизации работы с инженерными документами. Перед промышленной эксплуатацией организация должна утвердить регламент хранения документов, резервного копирования, проверки результатов OCR и распространения программы.

Опциональный точный режим скачивает официальные модели Tesseract `tessdata_best`; сведения о лицензии находятся в `THIRD_PARTY_NOTICES.md`.
