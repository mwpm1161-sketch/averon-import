# Changelog

## 1.0.0-rc8

- Добавлена ролевая авторизация ADMIN/USER на основе capabilities; настройки, управление пользователями и просмотр обращений доступны только соответствующим возможностям ADMIN.
- Добавлены app-owned сессии входа и выхода, защищённые cookie, CSRF-проверки и обработка завершения сессии.
- Добавлено администрирование USER-аккаунтов: создание пользователей, отключение, сброс пароля и удаление.
- Добавлен единый Support Reports workflow: инциденты экспорта, сообщения пользователей, снимки состояния и административная обработка обращений.
- Добавлена постоянная контекстная отправка «Сообщить о проблеме» для открытого документа; существующая отправка отчётов об ошибках экспорта сохранена.
- В управлении аккаунтами роль USER отображается как «Пользователь».
- Усилена изоляция сессий и временного состояния обращений; CSRF-защита применяется к изменяющим запросам.

## 1.0.0-rc7

- Исправлен запуск точного OCR на Windows: путь к `tessdata_best` больше не передаётся с буквальными кавычками.
- Каталог точных моделей теперь задаётся через временный `TESSDATA_PREFIX` без изменения системных настроек Windows.
- Добавлена блокировка окружения, чтобы стандартный и точный режимы не конфликтовали при параллельных вызовах.
- Добавлен регрессионный тест для путей с пробелами и кириллицей.

## 1.0.0-rc6

- Добавлены режимы «Стандартный» и «Точный инженерный».
- Реализована установка официальных моделей `tessdata_best` отдельным Windows-скриптом и через основной setup.
- В точном режиме каждый столбец распознаётся независимо с подходящим языком и сегментацией.
- Добавлено повторное OCR сомнительных ячеек после увеличения, CLAHE, Otsu/adaptive threshold.
- Добавлены отдельные ограничения для количества, массы и единиц измерения.
- Расширен консервативный словарь ОВиК и нормализация смешанной кириллицы/латиницы.
- Улучшено определение компонентов комплектного оборудования и коротких строк систем.
- Исправлено чрезмерное объединение самостоятельных строк.
- Добавлена индикация наличия точной модели в интерфейсе.
- Обновлена документация, сборка PyInstaller и сторонние уведомления.

## 1.0.0-rc5

- Исправлен критический сбой OCR на чистой Windows-установке: распознавание больше не требует необъявленную библиотеку pandas.
- Обработка результата Tesseract переведена на встроенный словарный формат `Output.DICT`.
- Если не обработана ни одна страница, интерфейс теперь показывает реальную причину ошибки.
- Для частичных ошибок отображаются не только номера страниц, но и текст причины.
- Исправлено отображение номера версии в интерфейсе.

## 1.0.0-rc4

- Исправлен `start_windows.bat`: удалена проблемная конструкция старой сборки с круглой скобкой.
- Файл запуска полностью переведён в ASCII + CRLF без кириллицы.
- Добавлены отдельные проверки `.venv\Scripts\python.exe` и `run.py`.
- Пути к Python и `run.py` теперь всегда передаются в кавычках и работают в папках с пробелами.

## 1.0.0-rc3

- Исправлен выбор установленной версии Python: установщик больше не вызывает жёстко `py -3.11`.
- Сначала используется совместимая команда `python`, затем резервно `py -3`.
- Неполная папка `.venv` удаляется автоматически перед повторным созданием.
- В журнал записывается фактически выбранная команда Python.

## 1.0.0-rc2

- Исправлена совместимость `setup_windows.bat`, `start_windows.bat` и `build_windows.bat` с Windows CMD.
- Все bat-файлы переведены в ASCII + CRLF.
- Установка теперь поддерживает как `py`, так и `python`.
- Добавлены пошаговая диагностика, обработка ошибок и журнал `setup_log.txt`.
