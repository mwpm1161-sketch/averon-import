# План проверки Averon Import

## Функциональная проверка

- загрузка корректного PDF;
- отказ при загрузке другого формата;
- выбор одной страницы, диапазона и нескольких диапазонов;
- автоматическое предложение страниц;
- ручное выделение области;
- отображение прогресса;
- обработка ошибки отдельной страницы;
- редактирование ячеек;
- изменение типа и статуса строки;
- выбор строк;
- поиск и фильтры;
- сохранение правок;
- копирование в буфер;
- изменение порядка столбцов;
- экспорт XLSX.

## Проверка данных

Для каждого эталонного PDF должен существовать вручную проверенный Excel. Метрики:

- найденные/потерянные строки;
- точность наименования;
- точность марки;
- точность единицы;
- точность количества;
- ложные строки;
- среднее время обработки;
- среднее время ручной проверки.

Количество и единица измерения являются критическими полями. Релиз не должен скрывать строки с низкой уверенностью.

## Первый эталон

Для текущего документа рекомендуется проверить страницы 18-20, затем весь диапазон спецификации 18-58.
