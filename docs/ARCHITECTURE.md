# Архитектура Averon Import

## Цели

- локальная обработка закрытых инженерных документов;
- разделение интерфейса, OCR, распознавания структуры и экспорта;
- возможность заменить OCR-движок или добавить новый шаблон спецификации;
- готовность к последующему подключению к Averon Core.

## Слои

```text
Интерфейс (HTML/CSS/JS)
        ↓ REST
FastAPI / API
        ↓
Сервисы приложения
├── PdfService
├── GostSpecificationDetector
├── TesseractOcrEngine
├── RecognitionService
├── ExcelExportService
├── WorkspaceService
└── JobService
```

### `PdfService`

Проверяет PDF и рендерит страницы через PyMuPDF. Результаты кэшируются в рабочем пространстве документа.

### `GostSpecificationDetector`

Определяет сетку таблицы геометрически:

- бинаризация изображения;
- морфологическое выделение линий;
- проекции по осям;
- выбор последовательности из десяти границ для девяти столбцов;
- удаление нижнего штампа по аномальному расстоянию между строками.

Ожидаемые пропорции столбцов хранятся отдельно и могут быть вынесены в профиль шаблона.

### `TesseractOcrEngine`

Поддерживает две стратегии:

- `standard` — два прохода по всей таблице (`rus` и `rus+eng`);
- `accurate` — `tessdata_best`, независимые проходы по каждому столбцу и повторный OCR сомнительных ячеек.

Геометрия таблицы не зависит от OCR. Поэтому модели, словари и даже сам OCR-движок можно заменять без изменения детектора и Excel-экспорта. Для каждого столбца задаются свой язык, режим сегментации, ограничения символов и порог повторного распознавания.

### `RecognitionService`

Объединяет страницы, классифицирует строки, переносит контекст раздела/системы, присваивает статусы и формирует данные интерфейса.

### `ExcelExportService`

Не зависит от OCR. Принимает уже проверенные строки и выбранный список столбцов. Поэтому в будущем он может использоваться другими модулями Averon.

### `WorkspaceService`

Сохраняет исходный PDF, кэш страниц, JSON-результат и выгрузки в изолированном каталоге документа. В Windows корневой каталог по умолчанию расположен в `%LOCALAPPDATA%\Averon Import\data`; он может быть заменён через `AVERON_DATA_DIR`.

### `JobService`

Выполняет тяжёлое распознавание в фоновом потоке и предоставляет прогресс интерфейсу.

## API

- `POST /api/documents` - загрузка PDF;
- `GET /api/documents/{id}/page/{n}` - изображение страницы;
- `POST /api/documents/{id}/suggest-pages` - поиск страниц спецификации;
- `POST /api/documents/{id}/recognize` - запуск OCR с параметром `ocr_mode`;
- `GET /api/jobs/{id}` - прогресс;
- `GET/PUT /api/documents/{id}/results` - получение и сохранение результата;
- `POST /api/documents/{id}/export` - выгрузка Excel.

## Расширение под Averon

При интеграции с основной платформой локальный `WorkspaceService` может быть заменён адаптером Averon Files, а локальная идентификация - Averon Auth. Формат строк и API распознавания менять не потребуется.
