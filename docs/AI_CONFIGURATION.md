# AI-проверка Averon Import

Averon Import поддерживает финальную AI-проверку после OCR. AI не заменяет Tesseract и не получает исходный PDF: модель получает только структурированные строки уже распознанной спецификации.

## Режимы

В интерфейсе доступны три варианта:

- **Без ИИ** — только OCR и правила Averon Import.
- **Локальная модель** — любой OpenAI-compatible HTTP API. По умолчанию используется адрес Ollama `http://127.0.0.1:11434/v1` и модель `qwen3:8b`.
- **Yandex Cloud AI Studio** — внешний OpenAI-compatible API Yandex Cloud.

Выбор хранится в браузере локально. Секретные ключи в браузер не передаются.

## Локальная модель

Минимальная конфигурация по умолчанию подходит для Ollama с OpenAI-compatible API:

```text
AVERON_LOCAL_AI_BASE_URL=http://127.0.0.1:11434/v1
AVERON_LOCAL_AI_MODEL=qwen3:8b
```

Для другого локального сервера измените URL и имя модели. Если сервер требует ключ:

```text
AVERON_LOCAL_AI_API_KEY=...
```

Averon Import отправляет запрос на `<BASE_URL>/chat/completions`.

## Yandex Cloud AI Studio

Для Yandex Cloud задайте:

```text
AVERON_YANDEX_AI_BASE_URL=https://ai.api.cloud.yandex.net/v1
AVERON_YANDEX_AI_API_KEY=<секретный API-ключ>
AVERON_YANDEX_AI_MODEL=gpt://<folder_id>/<model_id>/latest
```

Пример URI модели:

```text
gpt://<folder_id>/qwen3.6-35b-a3b/latest
```

API-ключ нельзя добавлять в Git, `.bat`, HTML/JavaScript или `result.json`. Для корпоративного развёртывания рекомендуется передавать секрет через переменную окружения или защищённое хранилище ОС/инфраструктуры.

## Дополнительные параметры

```text
AVERON_AI_TIMEOUT=120
AVERON_AI_BATCH_SIZE=10
AVERON_AI_TEMPERATURE=0
AVERON_AI_MAX_TOKENS=4096
```

`AVERON_AI_BATCH_SIZE` задаёт число строк в одном запросе. Небольшие пакеты снижают риск перепутать строки, слишком маленькие увеличивают число запросов.

## Защита инженерных данных

AI-слой специально ограничен:

1. Пустые поля запрещено заполнять значениями, придуманными моделью.
2. Строки, уже отмеченные сотрудником как `verified` или `edited`, повторно в AI не отправляются.
3. Перед применением ответа проверяются ID строки и допустимые поля.
4. Для каждого изменения сохраняются `ai_original`, `ai_changes`, `ai_provider`, `ai_model`, `ai_confidence` и `ai_reason`.
5. Любая строка, которую изменил AI, получает статус **«Требует проверки»**.
6. Если локальная модель или облачный API недоступны, OCR-результат не теряется. В результате сохраняется статус AI `failed` или `partial` и предупреждение.

## Данные при использовании Yandex Cloud

Исходный PDF, его изображения страниц и координаты таблицы не отправляются во внешний API. Передаётся только минимальный JSON с распознанными текстовыми полями, типом строки, разделом/системой и OCR confidence для этих полей.

Перед промышленным использованием внешнего API необходимо отдельно согласовать допустимость передачи этих данных в соответствии с внутренними требованиями НВСС.
