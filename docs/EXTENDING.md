# Расширение программы

## Новый формат таблицы

Создайте новый класс-детектор с методом:

```python
def detect(image, crop=None) -> DetectedTable:
    ...
```

Затем добавьте выбор профиля в `RecognitionService`. В перспективе рекомендуется вынести пропорции колонок, количество строк заголовка и словарь полей в JSON-профили.

## Новый OCR-движок

Реализуйте метод `recognize_table(image, table)`. Результат должен содержать список строк с полями:

- `values`;
- `confidences`;
- `bbox`;
- `source_row`.

Так можно подключить PaddleOCR, корпоративный OCR-сервер или специализированную модель без изменений интерфейса и Excel-экспорта.

## Новый экспорт

Добавьте сервис, принимающий проверенные строки и столбцы. Возможные направления:

- CSV;
- шаблон конкретной конфигурации 1С;
- JSON для Averon API;
- заполнение корпоративного Excel-шаблона;
- сравнение редакций спецификации.

## OCR-профили

Новая форма спецификации должна добавляться как профиль, содержащий количество и смысл колонок, ожидаемые пропорции, число строк шапки, языки OCR, допустимые единицы и правила классификации. Основной сервис не должен содержать условия, привязанные к конкретному проектировщику.

## Справочник исправлений

Следующий рекомендуемый модуль - SQLite-словарь, который будет хранить пары:

```text
исходное OCR-значение → подтверждённое сотрудником значение
```

Исправления должны учитываться только при достаточном совпадении контекста и оставаться проверяемыми.

## Принципы разработки

- не связывать OCR напрямую с интерфейсом;
- не хранить должности и роли в коде;
- сохранять исходные координаты каждой строки;
- не скрывать сомнительные результаты;
- критические числовые поля всегда оставлять проверяемыми;
- новые интеграции добавлять через сервисные адаптеры.
