# Сборка для Windows

## Вариант 1. Запуск из исходного кода

Используйте `setup_windows.bat`, затем `start_windows.bat`.

## Вариант 2. PyInstaller

1. Выполните установку.
2. Запустите `build_windows.bat`.
3. Скопируйте папку `dist\Averon Import\` на рабочий компьютер.
4. Установите Tesseract OCR 5 с русским языком.
5. Запустите `Averon Import.exe`.

## Корпоративный установщик

Для полноценного MSI/EXE-инсталлятора рекомендуется Inno Setup или WiX. Инсталлятор должен:

- установить приложение в `Program Files`;
- создать каталог данных в профиле пользователя или `ProgramData`;
- проверить Tesseract;
- создать ярлык;
- добавить программу в список удаления;
- сохранить версию и канал обновлений.

Tesseract можно включить в корпоративный установщик только после проверки его лицензии и выбранного дистрибутива организацией.

## Точные OCR-модели

Перед сборкой рекомендуется запустить `install_accurate_ocr_models.bat`. Каталог `averon_import/models` добавляется в PyInstaller-сборку автоматически. Сам исполняемый файл Tesseract в текущем релиз-кандидате остаётся внешней зависимостью Windows.
