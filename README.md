# Averon Import 1.0.0-rc7

**Averon Import** — локальное приложение для переноса табличных инженерных спецификаций из PDF в редактируемую таблицу с последующим копированием или экспортом в Excel (`.xlsx`).

Первая версия ориентирована на повторяющуюся девятиколоночную форму спецификации оборудования, изделий и материалов: позиция, наименование, тип/марка, код, производитель, единица измерения, количество, масса и примечание.

## Что нового в rc6

- два режима OCR: **Стандартный** и **Точный инженерный**;
- поддержка официальных моделей `tessdata_best` для русского и английского языка;
- раздельное распознавание каждого столбца в точном режиме;
- повторное чтение сомнительных ячеек после увеличения, удаления сетки и повышения контраста;
- отдельные правила для чисел, единиц измерения, наименований, марок и производителей;
- консервативный инженерный словарь типовых терминов ОВиК;
- нормализация распространённых смешанных кириллических/латинских обозначений;
- улучшенная классификация разделов, систем и компонентов комплектного оборудования;
- более осторожное объединение строк-продолжений.

## Основной сценарий

1. Загрузить PDF.
2. Выбрать страницы вручную, диапазоном или через автоматический поиск.
3. Выбрать режим распознавания.
4. При необходимости выделить область таблицы.
5. Запустить OCR.
6. Сравнить результат с PDF и исправить сомнительные значения.
7. Выбрать строки и столбцы.
8. Скопировать данные либо экспортировать `.xlsx`.

## Режимы OCR

### Стандартный

Использует установленные вместе с Tesseract языковые модели и два прохода по странице. Подходит для быстрого предварительного результата и качественных PDF.

### Точный инженерный

Использует `tessdata_best`, читает столбцы независимо и повторно обрабатывает наиболее сомнительные ячейки. Работает заметно дольше, но лучше подходит для мелкого ГОСТ-шрифта, русских технических терминов и смешанных обозначений.

Точные модели устанавливаются автоматически новым `setup_windows.bat`. Их также можно установить отдельно:

```text
install_accurate_ocr_models.bat
```

После установки моделей Averon Import необходимо перезапустить.

## Быстрый запуск в Windows

Требования для текущей тестовой сборки:

- Windows 10/11;
- Python 3.11 или новее;
- Tesseract OCR 5 с языками `rus` и `eng`.

Порядок:

1. Распаковать архив в отдельную папку.
2. Запустить `setup_windows.bat`.
3. При необходимости установить Tesseract в `C:\Program Files\Tesseract-OCR\`.
4. Запустить `install_accurate_ocr_models.bat`, если точная модель не установилась автоматически.
5. Запустить `start_windows.bat`.
6. Программа откроется по адресу `http://127.0.0.1:8765`.

Несмотря на браузерный интерфейс, PDF, OCR и Excel обрабатываются локально.

## Хранение данных

В Windows рабочие данные находятся в:

```text
%LOCALAPPDATA%\Averon Import\data\documents
```

Кнопка **«Сохранить правки»** записывает текущее состояние таблицы в локальный `result.json` рабочего документа. Исходный PDF не изменяется. Перед экспортом правки также сохраняются автоматически.

## Ограничение

OCR не является безошибочным источником. Количество, единицы измерения, марки и технические характеристики необходимо проверять по исходному PDF. Точный режим уменьшает объём исправлений, но не отменяет инженерную проверку.

Подробная документация находится в каталоге [`docs`](docs/USER_GUIDE.md).
